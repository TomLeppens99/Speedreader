# RSVP Speed Reader

A clean, minimalist Rapid Serial Visual Presentation (RSVP) speed reading application.

## What is RSVP?

RSVP displays words one at a time at a fixed focal point, eliminating eye movement and allowing faster reading. The red highlighted letter marks the Optimal Recognition Point (ORP) where your eye naturally focuses.

## Features

- Adjustable reading speed (60-1000 WPM)
- Center letter highlighting for optimal focus
- Clean, dark interface
- Load text files or paste custom text
- Progress tracking

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Space` | Play / Pause |
| `→` | Next word |
| `←` | Previous word |
| `↑` | Increase speed |
| `↓` | Decrease speed |
| `R` | Reset to beginning |
| `O` | Open file |
| `Esc` | Stop |

## Usage

```bash
python rsvp_reader.py
```

## Requirements

- Python 3.6+
- Tkinter (included with Python)
